## Ревью

Проверка отдельным агентом выявила два дефекта, устранённых до завершения:

- Ранний loading/error-return размонтировал выбранное окно: теперь при наличии selection окно остаётся в дереве.
- Снимок после сохранения перекрывал новые props: теперь снимок используется только пока входной объект
  остаётся прежним; новый объект из кэша обновляет просмотр. Старые чтения отменяются перед записью результата PATCH.

Дополнительно перед отправкой проверяется актуальная доступность edit, чтобы завершившаяся валидация
старой формы не отправила запрос после смены периода или отзыва прав.

## Уточнения интерфейса после обратной связи

- Блок позиций полностью скрыт при пустом items; непустой список имеет одну рамку и разделители между строками.
- «Редактировать» использует ghost-вариант без фона в обычном состоянии.
- Рядом с сохранением есть отдельная «Отмена»: проверено отбрасывание изменённого описания и возврат в просмотр.
- Крестик в edit закрывает окно полностью. Первый Escape переводит edit в просмотр, второй закрывает окно; фокус возвращается к строке.
- Проверены desktop и viewport 390×844: новые кнопки помещаются, горизонтального переполнения нет. Скриншоты обновлены.
- Повторно успешно выполнены npm run lint, npm run lint:architecture, npm run build и openspec validate expense-details-dialog --strict. Предупреждение Vite о размере chunks сохраняется.

## Обводка фокуса в редактировании

Сравнено с созданием дохода: там форма рендерится непосредственно внутри Dialog.Content.
Встроенная форма расхода теперь также не создаёт дополнительный DOM-контейнер.
Удалён промежуточный overflow-hidden без padding, на границе которого обрезался внешний ring.

Проверено в браузере: для 3 px обводки остаётся по 4 px внутри scroll-контейнера,
а до границ popup — 21 px на desktop и 17 px при viewport 390×844.
Мобильная форма прокручивается без горизонтального переполнения. Создание расхода
по-прежнему открывает один dialog со счётом и полями формы. Повторно прошли
npm run lint, npm run lint:architecture и npm run build (предупреждение о размере chunks сохраняется).
