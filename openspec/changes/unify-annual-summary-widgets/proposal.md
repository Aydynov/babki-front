# Proposal

## Why

Годовая сводка уже получает независимые валютные итоги, но отображает отдельную карточку для каждой валюты.
Повторяющиеся заголовки удлиняют боковую колонку и мешают воспринимать каждый показатель как единый блок.

## What Changes

- Объединить валюты внутри каждой из четырех карточек: «С прошлого года», «Накопления», «Доходы», «Расходы».
- Для показателей выбранного года показывать строки с кодом валюты, изменением к предыдущему году и суммой.
- Для «С прошлого года» группировать остаток и накопления внутри каждой валюты.
- Сохранить независимые суммы, нулевые валютные строки, основную валюту первой и ISO-порядок остальных.
- Для расходов окрашивать рост красным, снижение зеленым; знак процента и направление стрелки отражают изменение.
- Сохранить общую оболочку при загрузке, пустом ответе и ошибке, обеспечить читаемость на мобильном экране.

## Capabilities

### New Capabilities

- `annual-summary-presentation`: единые годовые карточки с валютными строками, сравнением и переносом прошлого года.

### Modified Capabilities

Нет. Новая спецификация уточняет годовое представление, сохраняя правила `multicurrency-dashboard-reporting`.

## Impact

- Виджеты `year-savings`, `year-incomes`, `year-expenses`, `last-year-rest` и при необходимости их сетка в `pages/main`.
- Представление валютных итогов использует существующие reports-модели и запрос пользователя.
- Возможен небольшой общий UI-компонент в `shared/ui` для одинаковых строк трех показателей.
- API, расчет финансовых показателей, месячные виджеты и графики не меняются. Новые зависимости не нужны.
