# Proposal

## Why

Шестеренка в деталях счета открывает окно, в котором смешаны переименование,
статичные сведения и действия жизненного цикла. Меню действий и отдельная короткая
форма сделают управление счетом понятнее, а статус будет виден сразу в его деталях.

## What Changes

- Заменить шестеренку на троеточие с меню «Редактировать», «Архивировать», «Удалить».
- Открывать из «Редактировать» общий ScrollDialog только с полем «Название счета»
  и кнопкой «Сохранить»; убрать из формы статичные сведения и действия жизненного цикла.
- Добавить «Статус» шестым статичным полем основной информации счета.
- Сохранить подтверждения, ограничения API, права, обработку ошибок и обновление данных.
- Для архивного счета оставлять редактирование и удаление, без повторной архивации.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `account-details-dialog`: меню текущего счета, отдельная форма названия и статус в основной информации.
- `personal-account-management`: убрать требование показывать неизменяемые поля в форме
  редактирования; уточнить управление архивным счетом через меню.

## Impact

Затрагиваются `src/features/manage-accounts/ui/manage-accounts-button.tsx`,
`src/widgets/accounts/ui/account-details-dialog.tsx` и локализация счетов.
Используются существующие Base UI Menu, иконка троеточия, ScrollDialog и AlertDialog.
API, контракты данных, зависимости и правила неизменяемости атрибутов счета не меняются.
