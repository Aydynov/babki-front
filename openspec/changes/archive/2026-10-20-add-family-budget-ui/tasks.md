# Tasks

Все задачи относятся к реализации после отдельного запуска apply. Проверки выполняются вместе со своим
этапом; результаты, среда, ограничения и точные команды записываются в `verification.md` этого change.
Личные сценарии остаются совместимыми, бэк не изменяется. Общего рабочего `npm test` нет.
