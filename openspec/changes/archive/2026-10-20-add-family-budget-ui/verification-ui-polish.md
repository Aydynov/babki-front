# Визуальная доработка — 2026-10-20

Запрос: привести семейные экраны к существующему стилю Babki, сохранить минимализм,
переиспользовать компоненты и улучшить понятность повседневных действий.

## Изменения

Переиспользованы Card, Button, Input, Switch, QueryError, Skeleton и установленные Lucide-иконки.
Добавлены адаптивные карточки групп, форма создания с пояснениями, компактная панель выбора бюджета,
раздельные блоки настроек, финансового доступа, участников и приглашений. Опасные действия вынесены
в отдельную область. Обновлены экран вступления, приглашения, обратная связь копирования и плашка
контекста бюджета в финансовых формах. Новых зависимостей нет.

## Ручные проверки

На dev-сервере с отключённым local auth зарегистрированы два новых тестовых пользователя с адресами
в домене `.invalid`. Их пароли случайны и не включены в артефакты. Через UI выполнены:

- Пустой список групп → создание семьи → семейный дашборд → настройки.
- Создание приглашения → регистрация второго пользователя → просмотр и явное принятие приглашения.
- Появление второго участника с четырьмя переключателями; изменение одного права и выдача полного
  управления; все четыре переключателя показывают актуальное состояние.
- Семейный → личный бюджет → список групп → создание → отмена.
- Отправка пустого названия: ошибка показана, поле получает `aria-invalid=true`.
- Подтверждение удаления открыто и отменено; группа не удалена.
- Светлая тема, desktop 1440 и mobile 320: настройки, список, панель выбора и диалог без горизонтального скролла.

Второй проход выполнен в браузере приложения на существующих seed-группах, без изменения их данных:

- Тёмная тема: список из четырёх групп, настройки семьи с тремя участниками, создание/отмена.
- Настройки на 1440, 613 и 320 px: `document.documentElement.scrollWidth <= innerWidth`.
- Исправлено предупреждение Base UI: для кнопок, отображаемых ссылками, задан `nativeButton=false`.
  После исправления повторный просмотр списка, настроек и создания не дал console error/warn.
- Наблюдалось состояние загрузки недоступной группы. Skeleton скрыт от accessibility tree;
  доступное имя статуса находится на внешнем контейнере.

Ограничение: попытка отдельной сетевой проверки loading/error списка прервалась из-за закрытия
Playwright MCP-контейнера; она не засчитана. В браузере приложения запрос несуществующей группы
оставался в loading до ухода со страницы, поэтому переход в серверную ошибку и её retry в этом
проходе не подтверждены. Ошибки используют существующий QueryError. Автоматизированное покрытие
всех визуальных состояний не заявляется. Финансовый регрессионный набор не перезапускался:
API, денежные расчёты и cache keys этим этапом не изменялись.
