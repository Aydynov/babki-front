# Verification

## Изменение

В `ExpensesByMonths` период запроса определяется только выбранным годом: 1 января — 31 декабря. Удалены подписка на выбранный месяц, проверка текущего года и импорт `endOfMonth`.

## Проверки команд

- `npm run lint` — exit 0.
- `npm run lint:architecture` — exit 0, `No problems found`.
- `npm run build` — exit 0. Vite предупредил о чанках больше 500 kB; сборка успешна.
- `git diff --check` — exit 0.

Общего настроенного тестового раннера нет. Автоматизированное тестовое покрытие не заявляется; ниже результаты браузерной проверки.

## Браузерная проверка

Запущен `npm run dev -- --host 127.0.0.1`, проверена основная страница `/main`.

- При выбранном феврале 2026 года годовой график содержит январь–декабрь; ответ содержит сентябрь с ненулевыми расходами.
- При выборе 2025 года зафиксированы параметры запроса `/reports/months`: `fromDate=2025-01-01`, `toDate=2025-12-31`. На графике отображаются месяцы выбранного года.
- После возврата к 2026 году и повторного чтения данных зафиксированы параметры `fromDate=2026-01-01`, `toDate=2026-12-31`; в данных представлены все 12 месяцев, включая ноябрь и декабрь после даты проверки.
- При переключении февраля на октябрь содержимое SVG годового графика идентично, число годовых запросов не изменилось. Месячный график и список расходов переключились на октябрь.
- В селекторе годового графика доступны RUB и USD. Выбор USD обновил выбранную валюту графика.
- Пустое состояние проверено временной установкой пустого массива в браузерный Query-кэш: отображается «Данные отсутствуют».
- Загрузка проверена временной установкой состояния pending/fetching без данных: `aria-busy=true`, отображаются заглушки и «Загрузка...».
- Ошибка проверена временной установкой error без данных: отображается сообщение и кнопка «Повторить». Нажатие выполняет повторный запрос полного 2026 года и восстанавливает график.
- Широкий экран: viewport 1200 px, график содержит все месяцы.
- Узкий экран: приложение загружено в iframe того же origin с реальным viewport 390 px. Ширина карточки 366 px, внутренний график шире карточки. Горизонтальная прокрутка работает (`scrollLeft=334`, `scrollWidth=698`, `clientWidth=364`), в SVG присутствуют все 12 подписей месяцев.

Состояния загрузки, пустого ответа и ошибки проверены на уровне UI-кэша, без имитации сетевых отказов сервера. Это подтверждает отображение состояний и работу повтора, но не поведение API при реальном сбое. Временные перехватчик параметров запросов, iframe и стили для снимков удалены.
